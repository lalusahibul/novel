# Panduan Mengunggah Novel Sendiri

Jika Anda ingin mengunggah novel sendiri, diperlukan beberapa penyesuaian agar novel dapat diproses dengan benar oleh simulator.

### 1. Persiapkan Novel
Siapkan novel Anda dalam format `.txt` (plain text).

### 2. Judul Bab
Tambahkan simbol `~` pada awal setiap judul bab.

**Contoh:**
```text
~Bab 1: Awal Mula
```

### 3. Format Paragraf
Tambahkan simbol `~~` pada awal setiap paragraf baru.

**Contoh:**
```text
~~Matahari pagi perlahan terbit di ufuk timur, menyinari desa yang masih tenang.

~~Angin sepoi-sepoi berembus melewati pepohonan saat penduduk desa mulai melakukan aktivitas sehari-hari.
```

### 4. Contoh Format Lengkap

Berikut adalah contoh bagaimana novel Anda seharusnya ditulis di dalam file `.txt`:

```text
~Bab 1: Awal Mula

~~Matahari pagi perlahan terbit di ufuk timur, memancarkan cahaya keemasan ke seluruh desa yang masih tenang.

~~John membuka matanya dan perlahan bangkit dari tempat tidur. Hari ini akan menjadi hari yang berbeda dari biasanya.

~~Ia berjalan menuju jendela dan melihat ke luar. Jalanan tampak jauh lebih sepi dari biasanya, dan perasaan aneh mulai menyelimuti dirinya.

~Bab 2: Orang Asing yang Misterius

~~Saat John berjalan melewati desa, ia melihat sosok asing berdiri di dekat jembatan kayu tua.

~~Orang asing itu mengenakan mantel hitam panjang dan topi bertepi lebar. Wajahnya tersembunyi di balik bayangan.

~~"Permisi," panggil John. "Apakah Anda sedang mencari seseorang?"

~~Orang asing itu perlahan berbalik, tetapi tetap terdiam.
```

### Catatan Penting
- Gunakan format `.txt` saja.
- Setiap judul bab harus diawali dengan simbol `~`.
- Setiap paragraf baru harus diawali dengan simbol `~~`.
- Berikan satu baris kosong di antara paragraf agar lebih mudah dibaca.
- Pastikan simbol `~` dan `~~` digunakan sesuai dengan fungsinya.
- Terapkan format ini secara konsisten agar novel dapat diproses dengan benar oleh simulator.
